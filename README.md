
# Login Programación Segura

Este proyecto fue desarrollado para el módulo **Programación Segura**. Consiste en un sistema de **Login con tres niveles de usuario** (Administrador, Usuario Avanzado y Usuario Básico).  
El administrador tiene permisos para **crear nuevos usuarios**. El sistema implementa buenas prácticas de seguridad, incluyendo:

- Uso de **procedimientos almacenados** para operaciones en la base de datos.
- Manejo de excepciones con `try-catch`.
- Arquitectura basada en **capas** (Modelos, Controladores y Vistas).
- Interfaz gráfica desarrollada en **Windows Forms (.NET, C#)**.

---

##  Requisitos Previos
- **Sistema Operativo:** Windows 10 o superior.
- **IDE:** Visual Studio 2022 (o compatible).
- **Framework:** .NET 6.0 (o versión usada en el proyecto).
- **Base de Datos:** SQL Server (Express o superior).
- **Herramientas adicionales:**  
  - SQL Server Management Studio (para restaurar la base de datos).
  - Git (si se descarga desde repositorio).
